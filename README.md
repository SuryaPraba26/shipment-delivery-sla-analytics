# Supply Chain Shipment & Delivery SLA Analytics

## Project Overview

This project analyzes supply chain shipment and delivery performance using MySQL. The analysis focuses on orders, shipments, carriers, warehouses, delivery tracking, SLA compliance, and product returns.

## Business Objectives

* Analyze order and shipment performance
* Measure delivery delays and SLA compliance
* Compare carrier performance
* Analyze warehouse delivery performance
* Identify products with higher return rates
* Generate monthly shipment and SLA metrics

## Database Tables

* Customers
* Products
* Warehouses
* Orders
* Order_Details
* Carriers
* Shipments
* Delivery_Tracking
* Returns

1. Top customers by order value
